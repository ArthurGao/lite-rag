# Keeping accounts safe

## Long passwords beat clever ones

Length matters more than odd symbols. A passphrase of four or five random words is easier to remember and harder to guess than a short password full of substitutions.

## One password per site

Never reuse a password. When one site is breached, attackers try the leaked email and password on other sites; this is called credential stuffing.

## Use a password manager

A password manager generates a different strong password for every account and fills it in for you, so you only remember one master password.

## Turn on two-factor authentication

Two-factor authentication asks for a second proof, such as a code from an authenticator app, after the password. An authenticator app is safer than text messages, which can be redirected by SIM swapping.

## Phishing

Check the address before typing a password. A login page reached from an email link may be a copy built to steal what you type.
